Main Modules of the LMS
1. Admin Panel

Admin can:

Manage Users (Students/Teachers)

Add/Update/Delete Courses

Manage Videos, Files, Assignments

Manage Payments & Orders

View Reports (sales, enrollments, quiz results)

Control system settings

2. Teacher Panel

Teachers can:

Create new courses

Upload video lessons (YouTube/Local file)

Upload PDFs, PPTs, files

Create quizzes & assignments

Check student submissions

Post announcements

3. Student Panel

Students can:

Create an account

Browse free & paid courses

Buy premium courses

Watch lessons after purchase

Download materials

Take quizzes

Submit assignments


4. Course Marketplace (Selling System)

Students can:

Browse paid courses

Add course to cart

Pay via:

bKash

Nagad

Rocket

After payment → Auto Enrollment

Can access purchased courses for life or limited time (as you set)

Admin can:

Set course price

Add discount

Approve payments (if manual)

View total sales

💰 How Course Selling Works
Step-by-step:

Student clicks Buy Course

Student chooses payment method

Student pays

Payment is verified

System updates:

enrollment table

payment table

Student gets instant access to course videos, files, quizzes

🗃 Database Main Tables
✔ users

Stores student/teacher/admin info

✔ courses

Stores course details + price

✔ lessons

Stores video lessons

✔ files

Stores PDFs, docs, attachments

✔ quiz & quiz_questions

Stores quiz structure

✔ enrollments

Which student purchased which course

✔ payments

Stores payment records, amount, status

✔ cart (optional)



1️⃣ Users Table

Purpose: সব ইউজারের তথ্য (Students, Teachers, Admin) রাখা।

Column Name	Type	Description
user_id	INT, PK, AI	ইউনিক ইউজার আইডি
name	VARCHAR	ইউজারের নাম
email	VARCHAR	ইউজারের ইমেইল
password	VARCHAR	পাসওয়ার্ড (hashed)
role	ENUM	‘student’, ‘teacher’, ‘admin’
phone	VARCHAR	ফোন নাম্বার (optional)
created_at	TIMESTAMP	অ্যাকাউন্ট তৈরি হওয়ার সময়
updated_at	TIMESTAMP	সর্বশেষ আপডেট সময়
2️⃣ Courses Table

Purpose: কোর্সের ডিটেইল + প্রাইস রাখা

Column Name	Type	Description
course_id	INT, PK, AI	ইউনিক কোর্স আইডি
title	VARCHAR	কোর্সের নাম
description	TEXT	কোর্সের বর্ণনা
teacher_id	INT, FK	কোন Teacher তৈরি করেছে
price	DECIMAL	কোর্সের দাম
discount	DECIMAL	ডিসকাউন্ট থাকলে
status	ENUM	‘active’, ‘inactive’
created_at	TIMESTAMP	কোর্স তৈরি সময়
updated_at	TIMESTAMP	সর্বশেষ আপডেট সময়
3️⃣ Lessons Table

Purpose: ভিডিও বা লেসন সংরক্ষণ

Column Name	Type	Description
lesson_id	INT, PK, AI	ইউনিক লেসন আইডি
course_id	INT, FK	কোন কোর্সের লেসন
title	VARCHAR	লেসনের নাম
video_url	VARCHAR	ভিডিও URL (YouTube/Local)
duration	TIME	ভিডিওর সময়কাল
created_at	TIMESTAMP	লেসন তৈরি সময়
4️⃣ Files Table

Purpose: PDF, PPT, Doc সংরক্ষণ

Column Name	Type	Description
file_id	INT, PK, AI	ইউনিক ফাইল আইডি
course_id	INT, FK	কোন কোর্সের ফাইল
file_name	VARCHAR	ফাইলের নাম
file_path	VARCHAR	সার্ভারে অবস্থান
file_type	VARCHAR	PDF, PPT, DOC ইত্যাদি
uploaded_at	TIMESTAMP	আপলোড সময়
5️⃣ Quiz & Quiz Questions Table

Purpose: কোর্সের কুইজ তৈরি

quiz table

Column Name	Type	Description
quiz_id	INT, PK, AI	ইউনিক কুইজ আইডি
course_id	INT, FK	কোন কোর্সের কুইজ
title	VARCHAR	কুইজের নাম
total_marks	INT	মোট মার্কস
created_at	TIMESTAMP	কুইজ তৈরি সময়

quiz_questions table

Column Name	Type	Description
question_id	INT, PK, AI	ইউনিক প্রশ্ন আইডি
quiz_id	INT, FK	কোন কুইজের প্রশ্ন
question_text	TEXT	প্রশ্নের লেখা
option_1	VARCHAR	অপশন ১
option_2	VARCHAR	অপশন ২
option_3	VARCHAR	অপশন ৩
option_4	VARCHAR	অপশন ৪
correct_option	ENUM	‘1’,’2’,’3’,’4’
6️⃣ Enrollments Table

Purpose: কোন স্টুডেন্ট কোন কোর্সে এনরোল করেছে

Column Name	Type	Description
enrollment_id	INT, PK, AI	ইউনিক আইডি
user_id	INT, FK	স্টুডেন্টের আইডি
course_id	INT, FK	কোর্স আইডি
enrolled_at	TIMESTAMP	এনরোলমেন্ট সময়
expiry_date	DATE	যদি টাইম-লিমিট থাকে
7️⃣ Payments Table

Purpose: পেমেন্টের রেকর্ড

Column Name	Type	Description
payment_id	INT, PK, AI	ইউনিক আইডি
user_id	INT, FK	কে পেমেন্ট করেছে
course_id	INT, FK	কোন কোর্সের জন্য পেমেন্ট
amount	DECIMAL	পেমেন্টের টাকা
method	ENUM	‘bKash’, ‘Nagad’, ‘Rocket’
status	ENUM	‘pending’, ‘completed’, ‘failed’
payment_date	TIMESTAMP	পেমেন্টের সময়
8️⃣ Cart Table

Purpose: Add-to-Cart সিস্টেম

Column Name	Type	Description
cart_id	INT, PK, AI	ইউনিক আইডি
user_id	INT, FK	কোন স্টুডেন্টের কার্ট
course_id	INT, FK	কোন কোর্স যোগ করা হয়েছে
added_at	TIMESTAMP	কার্টে যোগ করার সময়

Notes:

Checkout করার পর Cart থেকে ডাটা Enrollments & Payments এ যাবে।

একাধিক কোর্স একসাথে Cart-এ রাখতে পারেন।

Optional / Extra Tables

Announcements: কোর্স বা সিস্টেম নোটিশের জন্য

Assignments & Submissions: Teacher upload, Student submit

Reviews/Ratings: কোর্সের রেটিং & রিভিউ

Discounts/Coupons: ডিসকাউন্ট কোড

Reports/Logs: অ্যাডমিনের জন্য রিপোর্ট

💡 Summary:

Core Tables: users, courses, lessons, files, quiz, quiz_questions, enrollments, payments

Optional for Marketplace: cart

Extra: assignments, announcements, reviews, coupons
